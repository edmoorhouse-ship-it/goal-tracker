# goal-tracker

A Claude Code mod: a live Goal panel with cache warmth, context, session cost, usage limits, a task progress bar, elapsed/remaining time, and the task list.

## Install

```
/plugin install goal-tracker --marketplace edmoorhouse/goal-tracker
```

## Use

- `/goal <text>` sets the goal and opens the panel
- `/goal` reopens it, `/goal clear` resets it
